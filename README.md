## 📱 Брейкпоінти та адаптивність

Сайт розроблено за принципом **Mobile First** з використанням Flexbox та CSS Grid.

* **Mobile (до 767px):**
  * Одноколонковий макет (`flex-direction: column`, 1 колонка в Grid).
  * Навігаційне меню адаптується під вузькі екрани.
  * Таблиця розкладу має горизонтальний скролл (`overflow-x: auto`).

* **Tablet (`min-width: 768px`):**
  * Двоколонкова сітка карткових блоків (`grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`).
  * Блок навичок (Hard/Soft Skills) переходить у двоколонковий режим.
  * Форма контактів розміщується поруч із контактними даними.

* **Desktop (`min-width: 1024px`):**
  * Контент центрується з обмеженням `max-width`.
  * Трьохколонкове відображення основних блоків.
  * Збільшені відступи для комфортного читання на великих моніторах.
