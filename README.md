## 📱 Брейкпоінти та адаптивність

Сайт розроблено за принципом **Mobile First** з використанням Flexbox та CSS Grid.

* **Mobile (до 767px):**
  * Одноколонковий макет (`flex-direction: column`, 1 колонка в Grid).
  * Навігаційне меню адаптується під вузькі екрани.
  * Таблиця розкладу має горизонтальний скролл (`overflow-x: auto`).

* **Tablet (`min-width: 768px`):**
  * Двоколонкова сітка карткових блоків (`grid-template-columns: repeat(auto-fit, minmax(240px, 1fr))`).
  * Блок навичок (Hard/Soft Skills) переходить у двоколонковий режим.
  * Форма контактів розміщується поруч із контактними даними.

* **Desktop (`min-width: 1024px`):**
  * Контент центрується з обмеженням `max-width`.
  * Трьохколонкове відображення основних блоків.
  * Збільшені відступи для комфортного читання на великих моніторах.

## ♿ Доступність та якість (Accessibility)

* **Контрастність кольорів (WebAIM Contrast Checker / DevTools):**
  Усі тексти відповідають стандарту WCAG AA (контрастність $\ge$ 4.5:1).
  * Основний текст (`#1f2937`) на світлому фоні (`#ffffff`): **16.5:1** (PASS)
  * Заголовки та акцентні елементи (`#1e3a8a`) на фоні (`#f3f4f6`): **9.2:1** (PASS)
  * Кнопки та активні елементи (`#2563eb`) на білому фоні (`#ffffff`): **4.6:1** (PASS)

* **Навігація з клавіатури:**
  * Реалізовано банер швидкого переходу до основного вмісту (`.skip-link`).
  * Для всіх інтерактивних елементів налаштовано видимий фокус (`:focus-visible`).
  * Збережено логічний порядок табуляції (`tabindex`).

* **Семантика та ARIA-атрибути:**
  * Використано атрибути `aria-label` для іконок соцмереж та неочевидних посилань.
  * Використано атрибут `aria-current="page"` для позначення активного розділу меню.

* **Оптимізація ресурсів:**
  * Сумарний розмір усіх зображень у папці `img/` становить до 3 МБ.
  * Зображення стиснуті та оптимізовані за допомогою сучасних форматів WebP/JPG.
